# felladrin/awesome-ai-web-search

List of software that allows searching the web with the assistance of AI: https://hf.co/spaces/felladrin/awesome-ai-web-search

## tools

Web-search APIs you can wire into your own AI agents by pointing the agent at the API docs, or via an MCP server where one is offered. Building blocks, not standalone end-user apps.

Focused on general-purpose web search; domain-specific search APIs (academic papers, code repos, jobs, etc.) are out of scope.
